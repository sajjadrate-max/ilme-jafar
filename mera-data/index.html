ویڈیوز، تصویریں، PDF اور ہر قسم کی فائلیں انٹرنیٹ (کلاؤڈ) پر محفوظ کریں — موبائل کی میموری استعمال نہیں ہوتی۔ جتنے چاہیں فولڈر بنائیں، فولڈر کے اندر فولڈر بھی۔

⚙️ پہلی بار سیٹ اپ (صرف ایک بار)

فائلیں Vercel Blob کلاؤڈ اسٹوریج میں محفوظ ہوں گی۔ Vercel ڈیش بورڈ میں یہ کریں:

  1. Storage ← Create ← Blob منتخب کریں، اور اسے اس پراجیکٹ (ilme-jafar) سے جوڑ دیں۔ اس سے BLOB_READ_WRITE_TOKEN خود بن جائے گا۔
  2. Settings ← Environment Variables میں نیا ویری ایبل DRIVE_PASSWORD بنائیں اور اپنا پاس ورڈ لکھیں۔
  3. Deployments میں جا کر Redeploy کریں، پھر یہ صفحہ دوبارہ کھولیں۔
