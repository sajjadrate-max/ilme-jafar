سرور لگانے کا طریقہ

یہ کام صرف ایک بار کرنا ہے، تقریباً دس منٹ لگیں گے۔ سرور مفت ہے۔

  1. Render پر اکاؤنٹ بنائیںاپنے براؤزر میں render.com کھولیں اور GitHub والے اکاؤنٹ سے سائن اپ کریں۔
  2. نئی Web Service بنائیںاوپر New + دبائیں، پھر Web Service چنیں، اور Existing Image والا آپشن لیں۔
  3. انجن کا نام ڈالیںImage URL کے خانے میں یہ لکھیں:ghcr.io/imputnet/cobalt:11
  4. نام اور پلانسروس کا کوئی نام رکھیں، مثلاً my-cobalt۔ پلان میں Free چنیں۔
  5. دو سیٹنگز ڈالیںEnvironment Variables میں یہ دو لائنیں شامل کریں (اپنی سروس کا نام لگائیں، آخر میں / ضرور ہو):API_URL = https://my-cobalt.onrender.com/ PORT = 9000
  6. Deploy دبائیںچند منٹ انتظار کریں۔ جب Live لکھا آ جائے تو سرور تیار ہے۔
  7. یہاں پتہ ڈالیںاوپر "سرور کی ترتیبات" کھولیں، اپنا پتہ لکھیں، محفوظ کریں، اور "سرور چیک کریں" دبائیں۔ سبز نشان آ گیا تو سب ٹھیک ہے۔

مفت سرور 15 منٹ استعمال نہ ہو تو سو جاتا ہے۔ اس لیے پہلی بار ڈاؤن لوڈ میں تقریباً ایک منٹ لگ سکتا ہے، اس کے بعد تیز چلے گا۔

YouTube کبھی کبھی سرور والے کنکشن کو روک دیتا ہے۔ اگر صرف YouTube پر خرابی آئے اور باقی سائٹس چلیں تو وجہ یہی ہے۔

صرف اپنی یا اجازت والی ویڈیوز ڈاؤن لوڈ کریں، اور دوسروں کی ویڈیو ان کا نام دیے بغیر دوبارہ اپ لوڈ نہ کریں۔
